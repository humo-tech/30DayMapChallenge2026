# Day 6: Vintage — 実装解説

国土地理院のシームレス空中写真（関東）を 1 枚の紙に刷り、それが古びていく様子を見せる。始まりは真上から見た、画面いっぱいのいつもの航空写真。紙は最初から少しずつくしゃくしゃになり、色は縁から抜けて、ほんのりセピアの残るグレーに褪せていく。カメラは引きながら下がっていき、最後は机に置かれた 1 枚の古い写真を斜めから眺める。少し置いてから時間が巻き戻り、新しい写真に戻って次の周回が始まる。

| ファイル | 役割 |
|---|---|
| `app/maps/day06.vue` | ページ本体。タイルの貼り合わせ、くしゃくしゃの焼き込み、紙と机、時間の進行、カメラ |
| `app/maps/lib/shaders/vintageCommon.glsl` | 3 つのシェーダーで共有するもの（ノイズ関数、紙の縁までの距離） |
| `app/maps/lib/shaders/vintageCrumple.frag.glsl` | くしゃくしゃの高さマップを GPU で 1 回だけ描く |
| `app/maps/lib/shaders/vintagePaper.{vert,frag}.glsl` | 紙。高さマップで持ち上げ、陰影を付け、写真を褪せさせる |
| `app/maps/lib/shaders/vintageDesk.{vert,frag}.glsl` | 机の木目と、紙の落とす影 |

```
地理院タイル z10 × 72 枚 ─ stitch() ─▶ canvas 1784×1934 ─▶ CanvasTexture ─┐
                                                                            ├─▶ 紙（vintagePaper）
vintageCrumple.frag ─ bakeCrumple() ─▶ 高さマップ 1024² (R: 高さ, G: 擦れ) ─┘
                                                                            机（vintageDesk）
  毎フレーム
   └─ 時刻 t (0〜30 秒) → story(t) → fade / crumple / camera ─▶ uniform・カメラ位置
```

## 1. なぜ Navara ではなく素の Three.js か

Day 1〜5 は地球儀エンジンの Navara で描いてきたが、今回の主役は地図ではなく**紙**だ。紙を曲げる、机に影を落とす、斜めから眺める。どれも形そのものの話で、楕円体やタイルの仕組みは役に立たない。かえって邪魔になる。そこで航空写真は 1 枚の画像として読み込み、細かく分割した長方形（`PlaneGeometry`、約 370×400 分割）に貼って、あとはシェーダーで動かす。

Three.js 自体は Navara のためにすでに依存に入っているので、追加のパッケージはない（カメラ操作は `three/examples` の `OrbitControls`）。

---

## 2. 航空写真を 1 枚にする：`stitch()`

地理院タイル（`seamlessphoto`）は `access-control-allow-origin: *` を返すので、`crossOrigin = 'anonymous'` の `<img>` で読めば WebGL のテクスチャにできる。

範囲は経度 138.55〜141.0°、緯度 34.85〜37.0°（伊豆半島の付け根と秩父から銚子まで、相模湾から日光まで）。ズーム 10 の Web メルカトルのピクセル座標に直して、かかるタイル 8×9 = 72 枚を並行に読み、1784×1934 px の canvas に切り抜いて描く。読めなかったタイルは海の色のまま残る。

ズーム 10 にしたのは、全体を見せたときに画面幅（〜1900 px）と同じくらいの解像度になるから。ズーム 9 だと 4×5 枚で軽いが、最初の真上からの画面がぼやける。

斜めから見ると写真の奥がつぶれるので、テクスチャの異方性フィルタ（`anisotropy`）を最大にしている。

## 3. くしゃくしゃ：`vintageCrumple.frag.glsl`

### 布ではなく紙に見せる

最初は「折り目の線」をたくさん散らしていた。線の両側を山なり（または谷なり）に持ち上げ、それを何百本も足し合わせる。ところが、これは**布**に見える。山の頂上が丸く、斜面が曲面だからだ。

新聞紙をくしゃっと丸めて広げると、**平らな面（ファセット）が、鋭い折り目で継ぎ合わされた**形になる。そこで作り方を変えた。

1. 格子点を少しずつランダムにずらす（`JITTER = 0.27`、格子間隔の 27% まで）
2. 格子の四角をランダムな対角線で 2 つの三角形に割る
3. 各点にランダムな高さを与え、三角形の中は**直線補間**する

すると三角形の中は平面、辺のところで傾きが急に変わる。これが折り目になる。ずらしを大きくしすぎると細長い三角形ができて、黒い破片のような影が出る（0.35 では出た）。

格子が透けて見えないように、大きさと角度の違う 3 層を重ねている。

| 層 | 格子間隔（紙の高さ = 1） | 高さの振れ幅 | 角度 |
|---|---|---|---|
| 大 | 0.11 | ±0.006 | 0.4 rad |
| 中 | 0.045 | ±0.0025 | 1.3 rad |
| 小 | 0.02 | ±0.0008 | 2.2 rad |

その上に、古地図らしく**畳み跡**を 3 本足している（縦に 2 本、横に 1 本）。こちらは線の両側に (1 − 距離/幅)² で山・谷を作るので、なだらかに盛り上がる。

### 擦れ

折り目の頂上は擦れて白っぽくなる。高さマップの G チャンネルに「どれだけ擦れているか」を入れておき、紙のシェーダーが明るい色を混ぜる。畳み跡は強め、くしゃくしゃの折り目は大きい層だけを弱く。全部の折り目を擦れさせると、三角形の頂点から放射状の白い線が出て星のように見えるので、そこまではしない。

### GPU で 1 回だけ焼く

最初は JS で高さマップを計算していたが、1024² の画素それぞれで 3 層 × 最大 18 個の三角形を調べるので、**メインスレッドが 3.6 秒止まった**。同じ計算をフラグメントシェーダーにして、1024² の描画先（`WebGLRenderTarget`、半精度浮動小数）に 1 回だけ描くようにした。初期化は約 0.26 秒になった（シェーダーのコンパイルと読み戻しを含む）。

高さの最低点だけは、描いた結果を `readRenderTargetPixels` で読み戻して求める。紙の頂点シェーダーがこれを引いてから持ち上げるので、くしゃくしゃにしても紙は机にめり込まず、いちばん低いところで机に接する。

## 4. 紙：`vintagePaper.{vert,frag}.glsl`

### 持ち上げと陰影

頂点シェーダーは高さマップを読み、`(高さ − 最低点) × uCrumple` だけ紙を持ち上げる。分割数は約 370×400 なので、形はこの細かさまでしか出ない。

折り目をくっきり見せているのは陰影のほう。フラグメントシェーダーで高さマップの上下左右を読み、ピクセル単位で傾き（法線）を出して、北西の高いところからの光で明暗を付ける。`uRelief`（2.6）は陰影のための傾きだけを強調する係数で、実際の形は変えない。平らなところでちょうど明るさ 1 になるようにしてあり、光に向いた面は少し明るく、背を向けた面は暗くなる。わずかにハイライト（`spec`）も足している。

### 褪せる

写真の明るさ（輝度）だけを取り出し、暗い側 `DARK` と明るい側 `LIGHT` の 2 色の間に置き直す。どちらも、ほんのりセピアの残る温かいグレーだ。さらに全体を 15% だけ `LIGHT` に寄せてコントラストを落とす。写真の元の色は残さない。

| 定数 | 値 | 役割 |
|---|---|---|
| `DARK` | (0.39, 0.36, 0.32) | 最も暗いところの色 |
| `LIGHT` | (0.96, 0.94, 0.89) | 最も明るいところ・紙の色 |
| `STAIN` | (0.92, 0.88, 0.80) | 水染み・コーヒーの輪じみ |
| `EDGE` | (0.95, 0.91, 0.84) | 縁のくすみ |
| `BACK` | (0.89, 0.87, 0.82) | 紙の裏 |

色はここまで何度か変えた。濃いセピア → 赤みを抜いて黄色寄り → 白っぽく → 縁の焦げ茶を消して色褪せ → グレースケール → 少しだけセピアを戻す、で今の形になった。縁を濃い茶色にすると「古い」より「焦げた」に見える。

### 古びの細部

すべてノイズ関数（`vintageCommon.glsl` の `vnoise`・`fbm`）から作る。

- **水染み**：大きな斑のノイズの濃いところを `STAIN` 色で沈める
- **コーヒーの輪じみ**：紙の左下寄りに、ノイズで揺らした円環を 1 つ
- **しみ（フォクシング）**：細かいノイズの尖ったところだけを小さな点として暗くする
- **縁のくすみ**：縁から 0.05 以内を、ノイズで揺らしながら `EDGE` 色に
- **紙の粒**：とても細かいノイズと、縦に引き伸ばした繊維状のノイズ

### 縁から褪せていく

褪せ方は紙全体で一様ではない。`uFade` が上がるにつれ、縁から 0.4 の範囲が先に、ノイズでむらを付けながら進み、最後に中央まで届く。これで「時間が経つ」感じが出る。途中のフレームでは、中央にまだ元の航空写真の色が残っている。

## 5. 机と影：`vintageDesk.{vert,frag}.glsl`

机は 14×14 の大きな板で、引き伸ばしたノイズで濃い胡桃色の木目を描く。遠くほど暗くして、部屋の奥が闇に沈むようにしている。

紙の影は影マップを使わず、机のシェーダーが自分で描く。机の各点を紙の座標に直し、光と反対方向（南東）に少しずらした位置が紙の内側か（`paperDist`）を見て、ぼかしながら暗くする。紙がくしゃくしゃになるほど紙が机から浮くので、ずれとぼかしを大きくしている。

## 6. 時間の進行とカメラ

1 周 30 秒。`story(t)` が時刻から 3 つの量を返す。

| 量 | 進み方 | 効果 |
|---|---|---|
| `crumple` | 0.5 秒から 14 秒かけて 0 → 0.8。最初が速く、だんだんゆっくり（3 乗のイーズアウト） | くしゃくしゃの深さ |
| `fade` | 1.5〜10 秒で 0 → 1 | 褪せ |
| `camera` | 4〜13 秒で 0 → 1 | カメラの引き |

24〜29 秒で 3 つとも 0 に戻る（時間の巻き戻し）。最初は 8 秒あたりで一気にくしゃっと丸め、少し伸ばす演出だったが、最初から少しずつ進むほうが「古びていく」に合う。最初の数秒から見えるよう、ゆっくり始まる曲線ではなく、すぐに動き出す曲線にしている。

カメラは球面座標で動かす。

- **始まり**：ほぼ真上。紙がちょうど画面を覆う距離の 0.97 倍で、紙の外は見えない
- **終わり**：真上から約 57° 傾け、紙全体が収まる距離の 1.15 倍まで引き、少し方位を回す。紙を斜めから見ると、くしゃくしゃの凹凸がよく出る
- 終わりの方では、方位がゆっくり左右に揺れる

画面をドラッグ・ホイール・タッチするとカメラの自動運転が止まり、`OrbitControls` で自由に動かせる。右上のボタンで自動に戻すと、今の位置からなめらかに軌道へ戻る。時間の進行はカメラとは関係なく続く。

## 7. 調整ポイント

`vintageCrumple.frag.glsl`：

| 場所 | 今の値 | 効果 |
|---|---|---|
| `JITTER` | 0.27 | 格子点のずらし。上げると不規則になるが、細長い三角形の黒い破片が出る |
| `facets(...)` の 3 層 | 上の表 | 折り目の細かさと深さ |
| `fold(...)` | 幅 0.2、高さ ±0.012 | 畳み跡 |

`vintagePaper.frag.glsl`：

| 場所 | 今の値 | 効果 |
|---|---|---|
| `DARK` / `LIGHT` など | 上の表 | 色。3 番目（青）を下げるほどセピアが強くなる |
| `mix(aged, LIGHT, 0.15)` | 0.15 | 褪せの強さ（コントラストの落とし方） |
| `stain * 0.45` / `ring * 0.3` / `0.2 * fox` | — | 水染み・輪じみ・しみの濃さ |

`day06.vue`：

| 場所 | 今の値 | 効果 |
|---|---|---|
| `BBOX` / `ZOOM` | 関東 / 10 | 範囲と解像度 |
| `uRelief` | 2.6 | 折り目の陰影の強さ（形は変わらない） |
| `uLight` | 北西・高め | 光の向き |
| `story()` | 上の表 | 各段階のタイミング。`0.8 * crumpling` の 0.8 がくしゃくしゃの最終的な深さ |
| `pose()` の `1.15` / `1.0` | — | 終わりのカメラの距離（紙全体が収まる距離の倍率）と傾き（rad） |
